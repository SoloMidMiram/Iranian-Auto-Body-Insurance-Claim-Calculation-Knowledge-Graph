# Independent reference workflow — preparatory Issue #22 subset

The packet supplies 28 review slots across four branches: positive, classification boundary, missing evidence, wrong version/date, evidenced zero, unresolved terms and refusal predicates. These are selection roles, not fabricated claim facts or accepted answers.

1. A qualified external reviewer selects anonymized actual or independently authored claims and fills facts, exact authority/artifact/hash/clause/version/effective interval, intended decision, amount only when supported, rationale and reviewer/date. Check re-identification risk before adding files.
2. Keep model outputs withheld. Freeze and hash the reference response before exposing the candidate observations. Null expected amounts are unresolved, never zero.
3. A different operator runs the pinned model with exact input/graph/schema/source/parameter identities. Record Review decision, grant, selected branch, operators, guards, amount/scenarios and uncertainty.
4. Record match, actual defect, reference defect, authority pending or out-of-scope, with independent disposition. Preserve disagreements and block affected scope. A changed reference requires its own authorization; no frozen corpus is edited here.

No slot is filled with insurer credentials or synthetic numbers and then called validation. All 28 remain pending externally supplied facts and reference judgments. This preparation does not close #22, confer signoff or activate deferred field/production work.
