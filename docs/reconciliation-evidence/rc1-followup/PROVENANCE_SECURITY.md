Correction: shared validation enumerates the selected committed tree, rejects relevant index flags even without a modification, checks actual independent regular files and ancestors, rejects untracked/ignored source or data inputs and missing committed scopes, and compares actual content with trusted Git blobs. Stored blobs are read in one binary batch. Files differing from stored bytes must exactly equal Git's checkout-filtered form. The actual executable is never passed through a lossy clean filter. This preserves normal supported LF/CRLF and intentional deterministic checkout filters. Inspector content hashes remain identities of executed bytes rather than being silently normalized.

The same check is called by model_identity and inspector_identity, including end-of-execution rechecks already used by runner/investigation/comparator. File/corpus capture additionally rejects link substitutions. Existing distinct model, harness, worker shim, corpus and manifest identities, module-origin checks and before/after input checks remain intact.

Focused fixed evidence: `fix-byte-integrity.txt`. Windows cannot create native symlinks without additional privilege; that one explicit host skip remains visible and must be exercised on Linux CI. Generated __pycache__ bytecode and standard egg-info text metadata are excluded from source enumeration; arbitrary executable files inside egg-info are rejected. This is a bounded source-integrity check, not a sandbox against hostile Git executables/configuration, malicious filter commands, concurrent adversarial replacement between checks, or a compromised interpreter/bytecode cache.
