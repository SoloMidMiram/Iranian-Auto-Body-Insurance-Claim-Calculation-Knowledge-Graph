# Independent reviewer checklist: S05-S10

No qualified human acceptance is recorded. A software gate must not become a release approval.

| Decision | Evidence / remaining action | Status | Reviewer/date |
|---|---|---|---|
| Engineering | Reproduce exact parent/current witnesses; inspect changes; verify clean suite, 50 fixtures, graph/guard/plan checks, 38 mutants, docs and immutable original inputs | Automated evidence in final manifest; independent sign-off pending | PENDING |
| Domain interpretation | Confirm ownership routes/theft distinction, rescue scopes/denominator, proportionality and sequencing | AUTHORITY_PENDING | PENDING |
| Contractual authority | Select actual insurer/product/policy; authenticate governing policy/endorsement/manual, artifact/hash/clause, scope/version/dates and precedence | AUTHORITY_PENDING; insurer unselected | PENDING |
| Legal authority | Authenticate amendments/effective intervals and inaccessible circular; resolve Art. 10 transcription/ordering questions | AUTHORITY_PENDING | PENDING |
| Original inspection references | Review 41 authority-required nonpayable mismatches and separately diagnostic probes; adopt a new baseline only by explicit decision | Frozen comparator FAIL; no automatic rebaselining | PENDING |
| Bounded financial release | Establish every mandatory independent approval | BLOCKED | None recorded |
| Broader release / PRs / issues | Do not merge, approve or close automatically | BLOCKED; no remote changes | None recorded |

For each case preserve input/result digests, exact code/graph/schema revisions, dates/calendars, independent amount or blocker, artifact/hash/clause/effective interval, Review/grant/engine decisions, guards/traces, competing interpretations, reviewer/date and decision. Use PASS, FAIL, AUTHORITY_PENDING, EVIDENCE_REQUIRED or OUT_OF_SCOPE with rationale.

S05 requires explicit supported retained salvage and one deduction. S06 requires completed state plus proof on the ownership route. S07/S08 require nonconflicting disposition and bound supported value; a source token without an amount is insufficient. S09 requires the complete applicable record, even for zero. S10 keeps both scenarios unless genuine applicable authority resolves order. Questionnaire tokens and coincident outcomes do not supply that authority.

Synthetic records are labeled software assumptions. The calculator checks recorded fields and binding; it cannot independently establish that a claimed document hash or human attestation is truthful. Authenticate the source artifact and qualified review outside the arithmetic engine before payment/release.
